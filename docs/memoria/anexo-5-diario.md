Material de partida: `docs/diario-tecnico.md` tiene una entrada por cada sesión de trabajo con lo que se hizo, los problemas que aparecieron y cómo se resolvieron. Sirve para recordar fechas y detalles, pero no se debe copiar tal cual.

Formato propuesto para cada entrada:

| Campo | Contenido |
|---|---|
| Fecha y horas | Día de la sesión y tiempo dedicado |
| Etapa | Inicio, diseño, desarrollo o cierre |
| Qué se hizo | Dos o tres frases |
| Problemas | Qué falló y cómo se resolvió |
| Siguiente paso | Qué queda para la sesión siguiente |
